# สมุดพก ส.ส.

เว็บสาธารณะแบบไม่แสวงหากำไร สำหรับติดตามคำสัญญาหาเสียงของพรรคการเมือง และการทำหน้าที่ในสภาของ ส.ส. ทุกคน ตัวเลขทุกตัวมีที่มาและตรวจสอบย้อนได้

## ข้อมูลมาจากไหน
- การลงมติของสภา: [Politigraph โดย WeVis](https://politigraph.wevis.info) สัญญาอนุญาต CC BY-NC 4.0
- คำสัญญาหาเสียง: เอกสารนโยบายที่พรรคยื่น กกต. (มาตรา 57) อยู่ในไฟล์ `data/promises.json` พร้อมเลขหน้าหรือลำดับนโยบาย

## ระบบทำงานอย่างไร
1. ทุกวันที่ 1 ของเดือน GitHub Actions รัน `scripts/fetch.mjs` เพื่อดึงข้อมูลและคำนวณตามสูตรใน `scripts/compute.mjs`
2. มีด่านตรวจข้อมูลผิดปกติ ถ้าไม่ผ่าน ระบบจะหยุดเองและไม่แก้ข้อมูล
3. ถ้าผ่าน ระบบจะเปิด Pull Request ให้ผู้ดูแลตรวจ เมื่อกด Merge แล้ว Vercel จะสร้างเว็บใหม่จาก `scripts/build.mjs`
4. เว็บเป็นไฟล์นิ่งทั้งหมด:
   - ไม่มีฐานข้อมูล
   - ไม่มีระบบล็อกอิน
   - ไม่เก็บข้อมูลผู้เข้าชม
   - ไม่โหลดอะไรจากภายนอก

## สูตรการลงมติ
- **อัตราการลงมติ** = จำนวนครั้งที่ลงมติ (เห็นด้วย / ไม่เห็นด้วย / งดออกเสียง / เลือกผู้ถูกเสนอชื่อนายกฯ) หารด้วยจำนวนมติที่มีสิทธิ์
- **ไม่แสดงตนพร้อมพรรค:** ถ้า ส.ส. ของพรรคเกินครึ่ง (พรรคที่มีตั้งแต่ 3 คน) ไม่ลงมติในมติเดียวกัน ถือเป็นการตัดสินใจร่วมของพรรค และตัดมตินั้นออกจากตัวหาร
- **ประธานและรองประธานสภา** ไม่ลงมติตามธรรมเนียม จึงไม่นำไปเทียบกับคนอื่น
- **ข้อจำกัด:** แหล่งข้อมูลรวม "ลา" กับ "ขาดลงมติ" ไว้ด้วยกัน จึงยังแยกการลาตามระเบียบไม่ได้

## คำสั่ง
```
npm test          # ทดสอบสูตรด้วยข้อมูลสมมติ
npm run preview   # สร้างเว็บด้วยข้อมูลทดสอบสมมติ (ห้ามเผยแพร่) ที่ dist/
npm run fetch     # ดึงข้อมูลจริง (ต้องเข้าถึง politigraph.wevis.info ได้)
npm run build     # สร้างเว็บจากข้อมูลจริง
```
